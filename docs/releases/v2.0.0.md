# Steinel Mesh Gateway v2.0.0

Version 2.0.0 turns the single-device gateway into Steinel Mesh Gateway, with multi-device control, a four-language web interface and native Home Assistant integration.

### Changes

- Rename the project and repository to Steinel Mesh Gateway and reorganize the firmware configuration and components for multi-device operation.
- Add web-based selection of up to 16 imported devices, with separate web cards and native Home Assistant devices, without per-device YAML or a custom HA integration.
- Add local JSON backup import alongside the existing Steinel Cloud import, with automatic import of keys, device information and model bindings.
- Detect functions individually and add switching, brightness, automatic control, light threshold, run time, illuminance and motion/presence where supported. Read all Sensor elements and avoid exposing controls that do not apply to the device.
- Extend automatic device-name recognition from manufacturer and product identifiers, with per-device firmware/hardware information and persistent identity metadata.
- Filter the main list by manufacturer and separate unidentified entries for diagnostics and device reports.
- Add a web interface in English, Polish, German and French, with English as the default and a remembered language selection. Add French README documentation.
- Refresh the web layout with consistent expandable details, controls and diagnostics, orange checkboxes, lowercase hexadecimal identifiers and clearer device information.
- Reorganize cloud and local import into one collapsible section after setup.
- Make requested settings immediately visible in the web interface and Home Assistant, with background confirmation and recovery after rejected or unanswered commands. Keep actual output and sensor readings device-confirmed.
- Correct transient mode changes caused by mixing old and new replies. Prioritize output confirmation after control changes and retry lost or unsettled replies without waiting for the regular polling cycle.
- Improve Wi-Fi/Bluetooth coexistence and serialize browser reads, with faster refresh while command confirmation is pending.
- Add per-device availability and per-value expiry, bounded command queuing, reply correlation and fair polling when some devices or functions do not respond.
- Preserve selected Home Assistant devices, entities and area assignments while Mesh is disabled or firmware-update mode is active. Prevent redundant gateway entries from unused native API device slots.
- Add the gateway IP address to Home Assistant diagnostics.
- Update the existing optional Home Assistant control dialog and entity mappings, retaining one compact area tile without disabling supporting entities. Improve target detection to avoid similarly named entities from other integrations.
- Add per-element raw Sensor diagnostics in the web interface and an optional Home Assistant diagnostic entity.
- Add read-only device-report collection, observation markers and JSON download to simplify diagnostics and extending device support. Reports also work for imported devices not selected in HA, exclude network secrets and private identifiers, and remain downloadable after a connection loss.
- Reduce import and diagnostic RAM usage through flash-streamed backup parsing, bounded gateway buffers and browser-side report history.
- Strengthen backup validation, key-pair selection, model recognition and response matching, including interrupted-import protection and correct Scene Server identification.
- Provide factory and OTA images under the new project name with SHA-256 checksums, and use the new repository address for firmware updates.
- Update all README translations, compatibility information and screenshots, and expand protocol, import, transport, Home Assistant and browser regression tests.

### Supported devices

- NightmatIQ Plus, IS 180 (Mesh variant)
- L 800 SC, L 810 SC / C, L 820 SC, L 830 SC / C, L 835 SC / C, L 840 SC / C
- L 40 SC / C, L 42 SC / C
- L 270 digi SC, L 271 digi SC / C
- RS 200 SC / C, GL 80 SC / C
- Spot One SC, Spot Duo SC, Spot Way SC, Spot Garden SC, XLED home 2 SC

The list applies to Steinel Connect Mesh variants. Available functions depend on device equipment and firmware. Groups, neighbouring groups, Master/Slave, scenes and schedules remain managed in Steinel Connect.

Multi-device discovery requires Home Assistant 2025.7 or newer.
