# Steinel Mesh Gateway v2.0.2

Version 2.0.2 removes a command-queue delay across supported Mesh devices by allowing control writes to proceed while a state read is awaiting a reply.

### Changes

- Send switching, brightness, automatic-control and light-control property commands while a state GET is pending, without waiting for its reply or timeout.
- Track read replies and write completions separately, preserving the original read's destination, opcode, property and timeout.
- Prevent replies to reads started before a newer command from confirming that command. Keep device-confirmed Output reporting in Home Assistant.
- Preserve control sequences, bounded repetitions, transaction IDs and send spacing. Keep LC property payloads intact when constructing a GET.
- Retain Mesh radio traffic priority during paced control writes and expand regression coverage for overlapping reads and writes.

State reporting still depends on device replies and polling. This release addresses the confirmed wait inside the gateway; it does not guarantee immediate physical switching or resolve the cause of missing GET replies.
